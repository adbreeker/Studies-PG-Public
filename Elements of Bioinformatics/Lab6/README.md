## Section 1. What are bio databases for?
Biological databases exist for storage, organization, and sharing of biological data. Data is strored in a structured way so that it can be easily accessed and used. Each database entry is a so called **record**, which basically is a concrete physical thing, such as a gene, protein, or genome sequence. These records contain **evidence** about the biological entity in form of publications, experiments, computational analysis, etc. These help researchers to understand the functions and properties of biological entities, and jugge the reliability of the data. Databases also contain **cross-ref** links to other resources, which help to connect related information across different databases. This is important for comprehensive data analysis and research, as it helps to move accross different datasets and gain a holistic view of the biological entity being studied. Because scientific knowledge may change, databases store **version** histories so users can keep track of changes made to records over time.

## Section 2. Mini-glossary 
- **Record** - structured data object that represents one biological entity, such as a gene or protein. It's a basic unit of information used to store, retrieve, and link biological data.
- **Accession/ID** - a unique, stable identifier assigned to a record. It allows to easily find and reference a specific record within a database or across multiple databases.
- **Evidence** - supporting information that validates the data in a record. It can include experimental results, computational analyses, or publications.
- **Curation vs Prediction** - prediction is generated by some computational method, while curation is done by human experts who review and validate the data. The distinction helps the researchers to assess the reliability of the information.
- **Cross-reference** - links between related records in different databases. These are a bit like foreign keys in relational databases.
- **Isoform/Transcript** - represents an alternative version of a gene product produced from the same gene. Isoforms can have different functions or properties.
- **Taxonomy** - the classification of organisms into hierarchical categories like species. This helps to organize biological data based on evolutionary relationships.
- **Homology vs Similarity** - similarity is a measurable property, while homology is a binary relationship indicating common ancestry. Example of similarity is sequence alignment score.
