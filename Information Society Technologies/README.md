# Information Society Technologies

This repository contains coursework for the Information Society Technologies course.

## 📚 Course structure

The course consists of 3 segments:

1. **Lectures**
Overview and discussion of course topics.

2. **Project**
Preparation of research, experiment, and presentation for a selected subject.

3. **Seminary**
Additional presentation segment (topic currently unknown).

## 🎯 Project topic

**AI Models in Autonomous Game Development**

Main deliverables available in this repository:
- [AI Models in Autonomous Game Development - Research.pdf](AI%20Models%20in%20Autonomous%20Game%20Development%20-%20Research.pdf)
- [AI Models in Autonomous Game Developement - Presentation.pdf](AI%20Models%20in%20Autonomous%20Game%20Developement%20-%20Presentation.pdf)

## 🧪 Experiment scope

The experiment compares multiple AI models by asking each model to implement the same chess game from one shared game design document.
